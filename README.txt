ELINKER INTERACTIVE PROTOTYPE
==============================

This package was created from the prototype screenshots supplied in mo.zip.

How to use:
1. Extract this ZIP.
2. Open index.html in Chrome/Edge.
3. Use Next/Previous or select a step from the left menu.
4. Arrow keys also work.

Important:
The supplied ZIP contained screenshots only, not the original Elinker source code.
Therefore this package is an interactive presentation prototype using those exact
screenshots. To merge the actual workflow into elinker.lk, the site's source code
(or repository/hosting access) is needed.
